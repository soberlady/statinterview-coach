## 技术决策

- 共享样式统一颜色、页面宽度、字号、焦点、按钮与状态；报告先显示证据结论与下一步，再展开技术细节。
- 表单保留持久帮助文字，通过 aria-describedby 关联字段；等待与错误状态使用可感知通知。
- 追问进度归属原主问题，不改变正式题计数；窄屏实验表格局部横向滚动。
- 图表曾因 fixed 类名与工具样式冲突遮挡，改名避免定位冲突，实验数据未改变。
- 动效遵循减少动态效果偏好，补充跳至正文与键盘焦点；只读演示不伪装成实际提交。
