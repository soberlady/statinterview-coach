# 前端 UI/UX 优化与自检

日期：2026-10-03。范围：首页准备表单、练习室、报告、公开演示、实验与方法页面。

## 设计方向

使用暖白底色、墨色正文和深青色主操作，依靠字号、留白、边界和编号组织内容。共享样式集中在 `app/interface.css`，在原有页面样式之后加载；不增加外部字体、图片或产品运行依赖。

首页以三步流程和编号细线建立识别特征；练习页突出题目与回答区域；报告先展示结论与下一步，再提供可展开的技术细节；演示和实验页面使用同一套品牌、颜色及控件语言。动效限于短暂的颜色、边框和状态过渡，支持减少动态效果设置。

## 修复的问题

| 原有问题 | 本次处理 |
| --- | --- |
| 练习、演示、实验三种视觉风格割裂 | 统一颜色变量、页面宽度、字号层级、品牌标记、按钮、圆角、边框和焦点样式 |
| 首页内容平铺，填写前不容易理解过程 | 添加设定岗位、回答问题、回看证据的三步说明；桌面左右分区，窄屏按阅读顺序排列 |
| 输入提示随打字消失 | 保留示例占位文字，将字数与内容要求放到持久帮助文字，通过 `aria-describedby` 关联字段 |
| 表单等待、错误和操作反馈不够明确 | 为等待状态标记 `aria-busy`，关联错误消息，统一禁用、悬停、键盘焦点及错误样式；原有校验和请求保持不变 |
| 练习页题目、提示、回答框层次混杂 | 明确练习提示、题目信息和回答区域的间距，减少嵌套卡片；放大可读正文，清晰显示提交操作 |
| 手机端进度缺乏可理解的状态 | 保留完成数量与全部步骤，增加当前步骤语义，整理手机顶部的暂停按钮、会话状态和计时 |
| 追问时进度会指向下一道主问题 | 仅修正前端标记：追问显示为所属主问题的当前步骤，后端计数、选题及保存行为不变 |
| 报告卡片留白不均、证据文字过小 | 调整摘要、能力和证据区域比例，统一卡片和可靠性标记，完整换行展示引用来源；技术信息仍可展开 |
| 演示步骤在手机上截断 | 五个步骤在窄屏完整显示，保留可操作面积；补充回到练习的导航 |
| 实验图表出现大面积灰色遮挡 | 将图表的 `fixed` 类改为 `fixed-policy`，避开样式工具的固定定位类；没有修改图表数据 |
| 实验布局挤压表格且产生大块空白 | 数据卡片跨完整宽度；窄屏表格局部横向滚动，配可见提示和键盘焦点，不撑宽页面 |
| 辅助文字对比度不足、部分区域无法键盘访问 | 加深文字颜色，移除降低可读性的透明度；添加跳至正文、表格语义、滚动代码区焦点和反馈按钮状态 |
| 动态内容不易被辅助技术获知 | 对题目变化、进度和反馈使用局部状态通知，避免将整个演示工作区设为大范围通知区域 |

## 业务边界核验

- 对比修改前后 84 个 API、Agent、数据库定义和内容文件的 SHA-256，全部一致。
- 对比四个交互组件中的请求调用以及 React 状态、引用和副作用 Hook，全部一致。
- 新增步骤计算仅用于进度条展示；没有改变题目、评分、追问预算、接口参数、训练计划或 Agent 流程。
- 没有新增产品依赖。浏览器和可访问性检查工具放在被忽略的本地临时目录。

## 自检结果

1. **现有检查：** `npm run lint`、`npm run typecheck`、生产构建和 `npm test` 通过。现有测试共 87 项（14 项配置/页面检查、73 项 TypeScript 测试）。
2. **接口回归：** `npm run test:e2e` 通过，覆盖七题诊断、三题专项训练、恢复、报告、原子写入和策略重放。
3. **响应式：** 五类页面分别检查 1440、768、390、320 像素宽度，共 20 个布局组合；整页没有横向溢出。窄屏实验表格在自己的容器内滚动。
4. **自动可访问性：** axe 检查桌面和手机上的五类页面与演示全部阶段，共 18 个状态；另检查专项练习、无提示复测、训练报告 3 个状态，均无自动规则违规。覆盖 WCAG 2 A/AA、2.1 AA 相关自动规则及最佳实践；仍需人工读屏设备实测才能覆盖自动工具无法判断的内容。
5. **键盘及状态：** 检查跳至正文、原生必填校验、错误后保留表单并可重试、键盘滚动表格、报告展开、评分按钮选中状态，以及减少动态效果偏好。
6. **实际页面流程：** 完成八轮合成引导演示；验证追问仍标记原主问题，暂停/恢复正确；完成两题练习与一题无提示复测，检查提示隐藏、暂停/刷新恢复和最终报告。浏览器无运行异常。

上述检查使用本地合成数据或既有模拟评分服务，不调用真实模型或语音服务。截图、检查日志和临时验收脚本保存在 `.tmp/ui-review` 及 `.tmp/ui-*.log`，不进入产品构建。

## 展示页文案收尾（2026-10-08）

继续面向 Agent 开发岗位面试展示，按“决策行为 → 当前验证 → 方法依据”组织阅读。示例页用中文解释核实依据、保留能力状态、更新估计与回放，保留状态标识供技术交流；轨迹指纹与技术说明改为可展开内容。演示按钮明确表示查看下一步，避免让只读回放看起来像真实提交。

方法页将内部验收状态翻译为“待完成真人验收”“尚未完成真实测量”，补充平均误差、评分一致性、采信比例、理想参照和耗时分位的解释。历史基准仍明确绑定早期策略与冻结题库，版本信息保留在复现详情中；评分与选题误差单位分开说明。练习入口改为与首页实际流程一致的“开始一次面试练习”。

本轮仅调整展示组件、样式与说明，没有修改原始实验数据、API、选题和评分逻辑。lint、typecheck、生产构建与现有 108 项测试通过。浏览器检查 1440、768、390、320 像素宽度下的两页及全部五步演示，验证重新体验、键盘展开详情、中文状态、返回练习入口和页面无横向溢出；无浏览器运行异常。截图与临时检查脚本在 `.tmp/presentation-final`，本地预览为 `http://localhost:4175/`。
