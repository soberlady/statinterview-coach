## 本轮变化

- 首屏按具体训练主题给建议，同时展示可用于判断与待确认的回答数量。
- 已保存的逐项分数按已体现、部分体现、尚未充分体现、无法判断展示。错误原话不能因为有引用就成为优点；缺少可核对原话时不宣称已掌握。
- 待确认原因区分转写、内容评分未完成、评审分歧与证据不足。旧记录没有具体原因时明确采用证据不足，不猜测技术故障。
- 逐题展示相关原话；新评分保存已有复核说明，旧记录不补造说明或重新调用模型。
- 完整量表折叠为参考清单；补答草稿仅在当前页面内存中用于整理，不保存、不评分，也不覆盖原回答。
- 复测只对照完全相同的评分要求，排除不可靠记录；先前证据冲突则如实提示。连续训练的前测只采用来源训练的独立复测，不采用有提示练习。
- 保留原始回答、原分数、冻结题库、选题策略和审计轨迹。

## 真人验证仍需完成

### 第二轮实测后的修订（2026-10-16）

- 训练重点首项采用实际可启动题组的推荐方向与主题；同一评分点跨主题保留各自证据。
- 原题待确认时，关联同源、后续、可靠的验证追问，逐项展示追问结论，不把窄范围验证当成原题全部掌握。
- 首次创建诊断时预加载语音 SDK；连接准备期间复用加载结果，失败后可重试，不提前申请麦克风或创建付费 Agent。
- 音频轨道到达后并行读取网页题目与 Agent 状态；二者匹配才开启麦克风，保留错误回退与超时保护。
- 修正“房间与麦克风”统计标签为“房间连接”，新增轨道到达、题目校验、麦克风开启分段耗时事件。
- 本次网页更新不修改云端 Agent 实例配置。首次就绪的改善幅度仍需真人重测，不能从代码改动推断百分比。
