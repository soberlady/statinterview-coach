## 独立工程后续项

- **在途幂等**：并发相同请求可能重复调用评分，CAS/唯一约束只保证不重复保存。后续需定义跨实例的处理中、冲突、超时与崩溃恢复合同；本轮文档整理不实现该项。
- **多人访问门禁**：完整 API 仍为 owner-only；开放共享测试前完成主体认证、资源归属、配额与保留/删除规则，见[安全策略](../SECURITY.md)。
- **共享合同验证**：明确 Python 与 TypeScript 共同合同后扩大跨语言测试，不把数学夹具称作全会话等价。
- **依赖可复现性**：补充适用平台的传递依赖锁与哈希；在 2026-11-04 00:00 UTC 前复核现有 npm 临时例外，见[依赖风险](DEPENDENCY_UPGRADE_ZH.md)。
- **性能与可访问性**：测量语音首屏体积、首次就绪分段耗时，并补人工读屏与键盘验收；历史自动检查不替代当前版本真人测试。

每项作为独立任务定义范围和回归证据，不以大规模重构替代验收，也不将以上清单解释为已完成或已部署。
