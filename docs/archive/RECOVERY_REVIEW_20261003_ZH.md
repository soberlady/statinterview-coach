# 恢复与历史兼容：审查及修复记录（2026-10-03）

历史记录。以下是当时复现与修复的对应关系，不是当前开放缺陷清单；不记录私有会话、云端实例标识或临时备份路径。

| 当时复现 | 后续合同与回归 |
| --- | --- |
| 最后一题保存后响应丢失，原样重试被状态检查拒绝 | 已保存相同回答先走只读重放；完成确认独立重试，不要求重答 |
| 未提交文本刷新后丢失 | 题目绑定的本地草稿，24 小时访问时过期检查，提交确认或手动清除；存储禁用时不阻断作答 |
| 优先训练主题耗尽但其他主题仍可组成题组 | 遍历排序后的候选主题，保留同主题、不同题与复测排除；无完整组才停止 |
| 冻结策略仍读取可变题库 | 会话固定题库快照；旧配置映射历史版本；评分、训练和重放使用对应版本 |
| 浏览器故障验收只存在临时脚本 | 将草稿、响应丢失、最终确认失败和无提示复测纳入仓库的浏览器回归 |
