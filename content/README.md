# StatInterview 中文面试题库

这是面向中文数据分析岗位个人面试训练的结构化题库。当前共有 **48 道主问题、97 条验证追问**，覆盖 4 个能力维度，每个维度 12 道主问题、恰好 1 道锚点题。诊断固定使用其中两道公共题；专项训练另从非锚点题中安排两题练习和一道新场景复测。

## 文件

- `question-bank.json`：运行时使用的题库。
- `legacy/question-bank.v1.json`：旧版 24 题冻结快照，仅用于重现 v2 历史实验和原有评分夹具。
- `coaching-benchmark.json`：当前 v3 选题敏感性与重放回归，不是模型质量或学习收益实验。
- `validate-question-bank.mjs`：无第三方依赖的结构与约束校验脚本。

## 能力维度

| ID | 名称 | 题数 |
| --- | --- | ---: |
| `statistics_ml` | 统计与机器学习基础 | 12 |
| `experiment_causal` | 实验设计与因果分析 | 12 |
| `sql_python` | SQL、Python 与数据工程 | 12 |
| `business_analytics` | 业务分析与指标设计 | 12 |

每类题目均从难度 1 覆盖到难度 5。锚点题用于首次诊断和不同会话间的可比性，不代表正式、经过大样本标定的 IRT 锚题。

## 评分约定

每道题的 `rubric` 包含 3 至 5 条可以从回答原文取证的标准，权重之和为 1。评分器应：

1. 为每条标准提取支持证据、反对证据或标记“未提及”；
2. 按 0 至 4 分评价证据强度；
3. 由确定性程序按 `weight` 加权，不让语言模型直接决定最终总分；
4. 证据不足、转写不完整或评分接近决策边界时，从 `verificationQuestions` 中选择追问；
5. 追问后仍无充分证据时输出“证据不足”，不要强行给出确定结论。

明确错误且可逐字定位的回答可以是可靠的低分证据；“有可靠证据”不等于“答对”。短而完整的回答也可以被采信，不使用机械字数下限。无法定位证据、评分分歧或转写问题才需要可靠性处理。

建议的单条标准评分语义：

| 分数 | 含义 |
| ---: | --- |
| 0 | 未提及，或给出相反/明显错误的论述 |
| 1 | 提到相关词汇，但无法形成有效解释 |
| 2 | 核心方向基本正确，但缺少关键条件或存在局部错误 |
| 3 | 正确且较完整，并能结合题目情境解释 |
| 4 | 正确、完整，还能说明边界、风险或可执行验证方法 |

## 字段说明

- `id`：稳定且唯一；已有数据引用后不得因文案调整而改变。
- `skill`：四个固定能力维度之一。
- `difficulty`：人工初始化的 1 至 5 级难度，目前未经真实大样本标定。
- `jobTags`：用于岗位匹配和题库过滤。
- `question`：主问题。
- `expectedSeconds`：预计回答时间，用于剩余会话时间控制。
- `isAnchor`：是否为该维度的固定锚点题。
- `rubric`：可取证的评分标准与权重。
- `verificationQuestions`：证据不足时使用的验证性追问，至少两条。
- `verificationRubrics`：与追问一一对应的独立量表、难度及关联主问题标准索引；根据未覆盖或薄弱标准选择追问。
- `topic`：训练知识点分组，当前共 8 组。
- `family`：同类场景题的分组标识；复测须避开来源会话及前两题练习已出现的题族。
- `learningPoints`：练习阶段可见的方法提示；复测作答阶段隐藏。

## 校验

在项目根目录运行：

```powershell
node .\content\validate-question-bank.mjs
```

脚本会检查 JSON 可解析性、题目数量、ID 唯一性、字段类型、每类题目与锚点数量、难度覆盖、评分条目数量、权重之和、知识点、题族和独立追问量表。

## 内容边界

难度为初始设定，未经过真实作答标定。新增 24 题及学习提示由开发阶段编写，尚需熟悉数据分析的人工审题。48 题足够展示诊断到复测的个人项目闭环，仍不足以支撑长期高频训练；当前排重范围为同一条训练链，新建诊断可能重复。后续优先补充被频繁使用的知识点及题族，再用真实回答修订量表，而不是只增加数量。

## 题库发布与历史版本

`question-bank.json` 是内容编辑稿。运行时读取 `legacy/` 中已发布的不可变快照：

- `question-bank-v1`：原 24 题，供策略配置为 `{}` 的旧会话评分与回放。
- `coaching-bank-v1`：当前 48 题，供已有 v3 会话和新建会话使用。已有 v3 配置缺少题库版本时，始终解析为此版本。

新会话在 `policyConfig.questionBankVersion` 中保存题库版本；选题、提交评分、训练计划和报告回放使用该版本。旧会话创建新的训练时可使用当前训练题库，原会话本身保持旧版本。

修改已发布题目时，需要新增快照和版本，在 `app/lib/question-bank.ts` 注册、更新当前版本及配置校验，并保留旧快照。同步编辑稿后运行完整验证。`tests/question-bank-version.test.ts` 校验已发布快照哈希，禁止通过覆盖旧文件改变历史内容，并检查编辑稿与当前发布内容一致。不要为了让测试通过而重写旧版本的哈希。
